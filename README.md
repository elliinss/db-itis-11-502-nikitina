# Система управления университетом

## Описание предметной области
Данный проект представляет собой базу данных для управления учебным процессом в университете. Предметная область охватывает учет студентов, преподавателей, учебных групп, курсов и успеваемости. Система позволяет хранить информацию о том, какие студенты в каких группах состоят, какие преподаватели ведут какие курсы, а также какие оценки получают студенты по итогам сдачи курсов.

## Решаемая проблема
Основная проблема, которую решает данная система — автоматизация учета academic-процессов. Вместо бумажных журналов и разрозненных таблиц система предоставляет единое хранилище данных, позволяющее быстро находить нужную информацию: например, список студентов определенной группы, успеваемость конкретного студента или нагрузку преподавателя. Это упрощает работу деканата и преподавателей, а также позволяет формировать отчеты.
